# Interactive Mood Board 🎨

An interactive web-based tool designed for creators and designers to visualize their ideas. This project allows users to curate a "mood" by adding images, text, and customizing styles in a seamless, fluid interface.

[🔗 Live Demo](https://seefo123.github.io/Interactive-Mood-Board/)

---

## ✨ Features

* **Visual Curation:** Easily add and arrange images and text elements.
* **Full Customization:** Change notes colors.
* **Interactive UI:** A user-friendly workspace that responds to user inputs in real-time.
* **Modern Aesthetics:** Clean, minimalist UI to keep the focus on the creative content.

## 🛠 Tech Stack

* **HTML5:** Semantic structure for the board and its components.
* **CSS3:** Custom styling featuring Flexbox and smooth transitions.
* **JavaScript (ES6+):** Pure Vanilla JS for DOM manipulation and interactive logic.

## 📂 Project Structure

```text
├── index.html        # Main entry point
├── style.css         # All visual styling and layout rules
├── script.js        # Core logic and interactivity.
```
